Generic white surface container — the base for category tiles, trust strips, summaries, newsletter blocks.

```jsx
<Card hover><h3>Çekirdek Kahveler</h3></Card>
```

Crisp white, warm hairline border, soft `shadow-md` at rest. Set `hover` for the lift used on clickable cards. Radius is `--radius-xl` (22px); pass `style={{borderRadius:'var(--radius-lg)'}}` for tighter contexts.
