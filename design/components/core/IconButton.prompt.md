Compact icon-only button for toolbars and cards — search, account, wishlist heart, qty steppers.

```jsx
<IconButton icon="search" variant="soft" label="Ara" />
<IconButton icon="cart" variant="primary" label="Sepet" />
<IconButton icon="plus" variant="plain" size={38} />
```

Variants: `soft` (latte, default) · `primary` (espresso gradient) · `plain` (tinted, for qty +/-). Size sets the square edge in px; icon auto-scales to ~45%.
